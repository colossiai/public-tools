# **聖嚴說禪：超越對立，**

生死兩頭斷，一劍倚天寒

恐懼其實就是擺脫某些狀態，製作了強烈的對立。

# **與神對話：**

當渴望什麼時，也是強烈的表明了你缺失了這東西。因為製造了強烈的對立

# **基督教：**

愛和恐懼：愛超越了對立，恐懼是製造對立

愛裡沒有恐懼：對立被超越，沒有對立就沒有恐懼。

以前以為愛代表前進的力量，恐懼代表後退的力量，並不完全。

# **天主教：**

即使是出於惡劣的現狀也要讚美主。

先接受，再改變。也是超越對立

# **生命教育講座：**

一個人和父親的關係一定和解，不然整個人生都可能會有障礙，也是超越對立

# **投資：**

不要為投資失利煩惱，只需要盈虧兩頭斷，超越盈虧，順其自然

# **菜根譚:**
