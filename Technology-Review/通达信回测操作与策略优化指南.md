通达信软件内置的「程序交易评测系统」能帮助你用量化的方式验证交易策略在历史数据中的表现。我会为你介绍如何使用它进行回测，并分享一些提高回测效果的建议。

# 📊 通达信策略回测指南

## 1️⃣ 打开程序交易评测系统

你可以通过以下三种方式之一打开回测系统：

- **菜单导航**：依次点击菜单栏的 **"公式"** → **"程序交易评测系统"**

- **键盘快捷键**：直接按下 **Ctrl + S**

- **键盘精灵**：输入代码 **".903"** 并回车

## 2️⃣ 回测操作步骤

进行回测通常遵循以下流程，下图可以帮你一目了然地掌握整个过程：

A\[开始策略回测\] --\> B\[选择评测公式\];

B --\> C\[设置建仓规则\];

C --\> D\[配置交易方式\];

D --\> E\[设定平仓条件\];

E --\> F\[添加评测品种\];

G --\> H\[运行回测\];

J -- 是 --\> K\[考虑实盘验证\];

J -- 否 --\> L\[调整策略参数或逻辑\];

L --\> B;

下面我们对图中的关键步骤进行简要说明：

- **选择评测公式**：在「评测公式」栏，点击「选择指标」找到你编写好的**专家系统公式**（通常包含ENTERLONG（多头买入）和EXITLONG（多头卖出）信号。如果公式包含**参数**（如均线的周期），可以预先设置一个**范围**，以便后续优化。

- **设置建仓规则**：

  - 选择**评测时间段**，例如过去3年或5年。

  - 设置**初始资金**，通常默认为100万元。

  - 选择**开仓方式**，例如每次固定投入固定金额、固定股数或一定比例的资金。

- **配置交易方式**：

  - 建议设置**交易手续费**（包括佣金和印花税），这会影响回测结果的准确性。虽然比例不高，但累积起来也有影响。

  - 确定**交易时机**，例如通常选择以**收盘价**成交。

- **设定平仓条件**：

  - 根据你的策略逻辑，设置**止盈**、**止损**条件。

  - 你也可以选择**持有固定周期后平仓**（例如无论盈亏都持有5天后卖出）。 **注意**：平仓规则应**结合你的策略风格**（短线、中线等）和风险偏好来设定，不要简单照搬。

- **添加评测品种**：

  - 点击「添加品种」，你可以选择**个别股票**，也可以选择**全部A股**（通常用于测试选股策略）进行回测。

- **优化参数（如需要）**：

  - 如果你的策略有可调参数（如均线周期、RSI周期等），可以在「设置报告」步骤中**勾选「优化参数」**，并选择希望测试的参数范围。系统会自动遍历这些参数组合，帮你找到历史表现较优的参数值。

- **运行回测并分析报告**：

  - 点击「开始评测」，系统会自动运行并生成报告。**分析结果时**，除了关注**净利润**、**收益率**，更要重视以下关键风险指标：

    - **胜率**：盈利交易次数占总交易次数的比例。

    - **最大回撤**：资金曲线从最高点到随后最低点的**最大跌幅**。这反映了策略可能面临的**最糟糕情况**，是衡量策略风险和控制能力的重要指标。

    - **夏普比率**：衡量**风险调整后的收益**，值越高说明承担单位风险所获得的超额回报越高。

    - **交易次数**：回测期间发出的总信号数。次数过少可能说明策略迟钝，或样本外有效性待验证；次数过多则可能交易成本高昂。

## 3️⃣ 编写专家系统公式（策略）

要进行回测，你需要有自己的交易策略公式。通达信使用一种特定的公式语言。

- **创建路径**：功能 → 公式系统 → 公式管理器 → 用户 → 专家系统公式 → 新建

- **一个简单的双均线金叉死叉策略示例**：

> MA5 := MA(CLOSE, 5); // 计算5日均线
>
> MA10 := MA(CLOSE, 10); // 计算10日均线
>
> BUY_SIGNAL := CROSS(MA5, MA10); // 5日均线上穿10日均线，产生买入信号
>
> SELL_SIGNAL := CROSS(MA10, MA5); // 5日均线下穿10日均线，产生卖出信号
>
> ENTERLONG: BUY_SIGNAL; // 定义多头买入信号
>
> EXITLONG: SELL_SIGNAL; // 定义多头卖出信号
>
> *注：ENTERLONG和EXITLONG是通达信专家系统公式中识别**多头买入**和**多头卖出**平仓信号的关键词。*

## 4️⃣ 提高回测可靠性的建议

- **注意前复权处理**：强烈建议在回测时选择「**前复权**」数据，这能保证股价走势的连续性，避免因除权除息导致的价格突变和信号失真。

- **理解回测的局限性**：回测基于**历史数据**，其前提是市场参与者的思维模式和市场环境在未来不会发生剧烈变化。**过去有效不代表未来必然有效**，需警惕过度优化（Overfitting）产生的“完美曲线”，它在实盘中可能非常脆弱。

- **从简单策略开始**：不要一开始就试图设计一个包含众多参数和条件的复杂策略。**先从简单的思路（如基本的均线交叉、价格突破）开始验证**，逐步迭代和优化。

- **多次回测**：在不同的股票品种、不同的市场阶段（如牛市、熊市、震荡市）中进行回测，检验策略的**稳健性（Robustness）**。

## 5️⃣ 解读回测结果

查看回测报告时，可以重点关注以下指标：

| **指标名称** | **说明** | **参考标准** |
|----|----|----|
| **净利润** | 策略在回测期间的总盈利（总盈利 - 总亏损 - 手续费） | 越高越好 |
| **胜率** | 盈利交易次数占总交易次数的比例 | 通常越高越好，但也取决于盈亏比 |
| **最大回撤** | 资金曲线从最高点到随后最低点的最大跌幅，**非常重要** | **越小越好**，反映策略可能面临的最大风险边界 |
| **交易次数** | 回测期间的总交易次数 | 不宜过少（缺乏统计意义）或过多（摩擦成本高） |
| **夏普比率** | 衡量每承担一单位风险所获得的超额报酬 | 越高越好，说明风险调整后收益高 |
| **盈亏比** | 平均每笔盈利金额与平均每笔亏损金额的比值 | 越高越好，说明盈利能力强 |
