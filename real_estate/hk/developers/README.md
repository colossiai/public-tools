# 屋苑 -> 发展商对照表（维基百科为主，中原屋苑专页补充）

- `estate_dev.py`：`python3 -I estate_dev.py`。读入 `__temp/hk_real_estate/raw/`，用中文维基百科建立 `(estate, hma)` -> 发展商的对照表。输出两个文件：`estate_developers.csv` 是对上了的屋苑，`estate_developers_unmatched.csv` 是没对上的屋苑，按成交量排序，方便手动补充。维基原文缓存在 `__temp/hk_real_estate/wiki/`。
  - 维基来源：
    - 「香港私人屋苑列表」：有發展商栏。分期的屋苑，例如 日出康城第一期，同时也按总名对应，各期发展商合并。
    - 「香港資助出售房屋列表」：居屋，记为 房委會；行内写明房协的记为 房協。
    - 「租者置其屋計劃」：39 个邨，记为 房委會。
    - 以上都对不上、且成交 ≥20 宗的屋苑，再查同名条目信息框的「發展商」栏。条目内容要提及该区或片区才收。
  - 维基仍然对不上、成交 >10 宗的屋苑，再用中原屋苑专页补充：
    - `centaline_dev.py` 用 raw 成交记录里的 `typeCode` 直接打开 `hk.centanet.com/estate/<名>/<typeCode>`，读页面上的「發展商」栏。因为按代码打开，不需要比对名称；一个屋苑有多个代码时，最多试 3 个。
    - 结果存为 `centaline_developers.csv`（`developer` 栏保留中原原文，以「/」分隔），页面内容缓存在 `__temp/hk_real_estate/centaline_estate.json`。
    - 维基对不上、成交 >10 宗的 897 个屋苑中，246 个在中原有发展商，主要是新盘和九龙站一带的屋苑。其余大多是 1960–90 年代的单幢旧楼，中原页面的发展商栏也是空的。
  - 维基和中原都对不上的，用 `manual_developers.csv` 手动补充（附资料来源网址）。查不到可靠原始发展商的旧楼不填，留在 unmatched，例如 安和園、聯盛大廈、合眾樓、美景樓。
  - 执行顺序：`estate_dev.py` -> `centaline_dev.py` -> 再跑一次 `estate_dev.py`，把中原的结果合并进来。
  - 对应方法：依次用 `bigEstateName`、`estateName`、`buildingName` 比对维基名称。比对前会去掉空格、间隔号（．·‧），并统一括号。名称相同时要地区（十八区）也相同才收，同名但在别区的不收。
  - 公司名称会统一写法，例如 新鴻基地產 -> 新鴻基，恒基地產 / 恆基兆業 -> 恒基兆業，地鐵公司 / 港鐵公司 -> 港鐵。但集团的合并或改名不会归并，例如 和記黃埔 不并入 長實，九廣鐵路公司 不并入 港鐵。
  - 覆盖率（维基加中原）：全部成交 81%，二手成交 74%，`../analysis-20261029/estates_3y.csv` 的 362 个屋苑中有 358 个。仍然没有发展商、成交 >10 宗的有 651 个，共约 1.37 万宗，几乎全是单幢旧楼。
  - 试过但没有用的来源：
    - 一手住宅物业销售资讯网（SRPE）的结构化数据没有发展商栏，价单上也没有，只有售楼说明书写明卖方。
    - 美联的屋苑数据 API 需要授权，所以没有使用。
  - 准确度（只计维基来源）：与中原的发展商标签核对，新鸿基 160 个里有 156 个相符，信置 71 个里有 68 个相符。不符的多是合资或资料差异，例如 柏景灣、維港灣 维基只写 港鐵。

`estate_developers.csv` 的栏位：

| 栏位 | 定义 |
|---|---|
| `estate` / `hma` / `district` | 屋苑名、中原片区、中原区名。与 `../analysis-20261029/estates_3y.csv` 的 `estate` / `hma` / `district` 相同，可以直接 join |
| `developers` | 发展商，以「；」分隔，顺序与维基相同。合资项目有多个 |
| `wiki_name` | 维基上的名称 |
| `matched_on` | 用中原哪个名称对上的（`bigEstateName`、`estateName` 或 `buildingName`）；来源是中原屋苑专页时，填的是 `typeCode` |
| `match` | `name+district` 表示名称和十八区都相符。`name_only(無地區)` 表示维基来源没有地区，只有租置计划的邨属于这种。`typeCode` 表示按中原代码直接对上（来源是中原屋苑专页）。`manual` 表示手动补充 |
| `wiki_district` / `wiki_year` | 维基上的地区、入伙年份 |
| `source` | 来源：`私人屋苑列表`、`私人屋苑列表(各期合併)`、`資助出售房屋列表`、`租者置其屋計劃`、`維基條目信息框`、`中原屋苑專頁`、`手動補充` |
| `n_trans` | 该屋苑在 raw 里 3 年的成交宗数，包括一手和特殊成交 |
