# 新鸿基（SHK）屋苑统计

中原的发展商代码是 `de183`。数据是 3 年内的成交实价（中原成交 API，大部分来自土地注册处），截至 2026-10-29。
中原的发展商标签包括合资项目，例如沙田第一城、日出康城，所以这些屋苑也算在内。

所有 CSV 都是 UTF-8 with BOM，可以直接用 Excel 打开。尺价都按实用面积计，单位是港元/呎。

## 两个比较期

| 简称 | 期间 | 说明 |
|---|---|---|
| base | 2023-11-01 ~ 2024-10-31 | 基期。2023-10 之前的数据不完整，所以从 11 月开始 |
| last | 2025-11-01 ~ 2026-10-31 | 近 12 个月 |

计算升幅时只用二手成交，一手和中原标记的「特殊成交個案」都已剔除。日期以合约日期（`insDate`）为准。

## 文件

| 文件 | 内容 |
|---|---|
| `shk_estates.csv` | SHK 所有屋苑的分布，每行一个屋苑，共 227 个。只要 3 年内有成交（包括一手）就收录 |
| `shk_estates_3y.csv` | 有 3 年升幅的 SHK 屋苑，共 96 个，条件是两期各至少 10 宗二手成交。按 `adj_chg` 由高到低排列 |
| `shk_top20.csv` | 前 20 名。只计 `low_sample=False` 的屋苑，也就是两期各至少 20 宗 |
| `shk_top20_10k_20k.csv` | 同上，再加条件：近 12 个月中位尺价在 10,000–20,000 之间 |
| `shk_top20_10k_20k_2005plus.csv` | 尺价 10,000–20,000，且 2005 年或之后入伙。合乎 20 宗门槛的只有 16 个，所以这个文件用 10 宗门槛，样本少的要看 `low_sample` |

## `shk_estates.csv` 的栏位（由 `../dev_agg.py` 生成）

| 栏位 | 定义 |
|---|---|
| `terr` | 大区：港島、九龍、新界東、新界西。中原把将军澳归入九龙，把华景山庄归入九龙 |
| `district` | 中原用的十八区名称，例如 `將軍澳 (西貢區)` |
| `hma` | 中原的片区（`districtName`），例如 `調景嶺` |
| `estate` | 屋苑名。依次取 `bigEstateName`、`estateName`、`buildingName` 中第一个不为空的 |
| `n_3y` | 3 年内全部成交宗数，包括一手和特殊成交 |
| `n_firsthand` | 其中的一手成交宗数 |
| `n_l12_2nd` | 近 12 个月的二手成交宗数，已剔除特殊成交 |
| `med_unit_l12` | 近 12 个月二手成交的中位尺价。没有成交时留空 |
| `med_price_m` | 3 年内全部成交的中位总价，单位是百万港元 |
| `opYear` | 入伙年份（中原原文，例如 `2005年`） |
| `adj_chg_3y` | 全港表（`../estates_3y.csv`，MINN=20）中的 `adj_chg`。屋苑不在那张表里时留空 |

## `shk_estates_3y.csv` 和三份 top 20 的栏位（由 `../dev_rank.py shk shk` 生成，前置步骤见该文件开头的注释）

| 栏位 | 定义 |
|---|---|
| `rank` | 在该文件内的名次，按 `adj_chg` 由高到低 |
| `terr` / `district` / `hma` / `estate` | 同上 |
| `built` | 入伙年份（整数）。中原没有资料的留空，公屋通常没有 |
| `n_base` / `n_last` | 两期各自的二手成交宗数 |
| `low_sample` | `True` 表示两期中有一期少于 20 宗，升幅只可作粗略参考 |
| `med_base` / `med_last` | 两期各自的中位尺价 |
| `median_chg` | `med_last / med_base - 1`，单位是 %。会受成交组合影响，例如某一期较多高层或大单位成交 |
| `adj_chg` | 组合调整后的升幅，单位是 %，排序就用这个。做法是在屋苑内做回归：log(尺价) ~ 期间 + 座数 + 楼层（低/中/高）+ log(面积)，结果取 `exp(期间系数) - 1` |
| `hk_rank` | 在全港 362 个屋苑中的名次（MINN=20，按 `adj_chg`）。不在全港表里的留空 |
| `med_area` | 3 年内二手成交的中位实用面积，单位是呎 |
| `n_total` | 3 年内二手成交总数，包括两期之间那 12 个月 |
| `n_firsthand_3y` | 3 年内一手成交宗数 |

## 注意

- 新盘例如 Novo Land、Sierra Sea、Yoho West、天璽．天 没有 3 年前的二手成交，所以没有升幅，只会出现在 `shk_estates.csv`。
- `median_chg` 和 `adj_chg` 差距很大时，通常是样本太少；这时宜参考成交量较多的屋苑。
